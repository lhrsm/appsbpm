# Portal do Associado SBPM

Desenvolva um aplicativo que pegue informações dessas seguintes urls:

https://www.sbpmbahia.com.br
https://www.sbpmsanitas.com.br/piloto

Esse aplicativo terá como funções que os associados e dependentes façam consultas dos seus cadastros. 
Ex: limite disponível, carência de exames, clinicas e parceiros conveniados, informe de rendimentos e que gere uma carteirinha de identificação tanto do titular quanto dos seus dependentes, caso houver.
Para eu extrair essas informações, eu precisarei ter um api da url https://www.sbpmsanitas.com.br/piloto
Será essa api que irá me passar as informações que serão extraídas nesse app. A tela de login será composta pela logo anexada e a forma de acesso será a matricula do associado.
